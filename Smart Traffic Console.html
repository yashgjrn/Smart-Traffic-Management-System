Visual companion to the C++17 console prototype. It applies the same rules from the README in the browser. No sensors, no live traffic, sample penalties only.

Vehicle counts at the intersection

Emergency directions go first, then by vehicle count (ties keep N, E, S, W order). Green time is min(15 + 2 × count, 60) seconds, and 0 for an empty direction.
